# LOCUS CIT // Frontend (Owner B)

Interactive Command Matrix & Campus Logistics Operations Deck for Chennai Institute of Technology.

Next.js 15 (App Router) + TypeScript + Tailwind CSS tactical military-industrial aesthetic. Talks directly to the backend REST API described in `docs/API_CONTRACT.md` via `NEXT_PUBLIC_API_BASE_URL`.

## Key Features
- **Tactical Dense Matrix**: High-information density timetable grid with dynamic Group / Faculty / Room pivots.
- **Scenario Simulation Matrix**: Real-time switching between Baseline (189 sessions), Spectra Fest Surge, Disruption Repairs, and Exam Schedules.
- **Role Impersonation**: One-click switching between `admin`, `department_coordinator`, `faculty`, and `club` workflows.
- **Audit & Inspector Deck**: Live diff inspection, conflict telemetry, room utilisation radar, and approval chains.
- **Tactile UI System**: Custom hardware-inspired tactical buttons, status badges, and telemetry indicators.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the LOCUS command center.

## Production Build & Linting

```bash
npm run lint
npm run build
```
