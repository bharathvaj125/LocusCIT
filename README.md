# LocusCIT - Campus Scheduling and Venue Management (CIT)

Crunch Week, TechZephyr 4.0, IIT Bhubaneswar. Generates the semester timetable,
midsem exams and Spectra week booking decisions for the CIT dataset, repairs the
timetable after disruptions with minimal moves, and requires Admin approval for changes.

## Layout
| Path | Purpose |
| --- | --- |
| `frontend/` | Next.js web app |
| `backend/` | FastAPI API, CP-SAT solver, validation, exports |
| `starter_pack/` | Official data, validator and examples (unmodified) |
| `exports/` | `schedule.json`, `schedule_after.json` generated by the app |
| `docs/` | API contract, decisions, test reports |

## Branches
`main` is stable. Work on `feature/backend` and `feature/frontend`; merge via small PRs.
